# QR Code Generator 1.0

Open `index.html` directly in a modern browser. Paste a complete HTTP or HTTPS website or file URL, select **Generate QR code**, then select **Download PNG**.

The QR code encodes the supplied URL. When someone scans a file link, the destination determines whether the browser opens or downloads the file. Generation works offline, while opening the destination requires access to that URL.

Everything needed to run the app is embedded in the HTML. Version 1.0 stores no history and has no user accounts.

The HTML includes [Project Nayuki's QR Code generator](https://github.com/nayuki/QR-Code-generator/tree/v1.8.0), version 1.8.0, under the MIT license.
